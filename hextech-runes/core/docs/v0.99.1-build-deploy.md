# HextechRunes v0.99.1 build/deploy notes

This branch contains a v0.99.1-lite compatibility build for HextechRunes.

## Requirements

- .NET 9 SDK
- Godot 4.5.x Mono editor
- Slay the Spire 2 v0.99.1 game assemblies backed up under:
  `hextech-runes/core/versioned-dll-backups/0.99.1/game-refs`
- Required reference DLLs in that folder:
  - `sts2.dll`
  - `GodotSharp.dll`
  - `0Harmony.dll`

## Build DLL

From `hextech-runes/core`:

```powershell
dotnet build .\src\HextechRunes.csproj -c Release `
  -p:HextechSts2Target=0.99.1 `
  -p:GameDataDir=".\versioned-dll-backups\0.99.1\game-refs"
```

The v0.99.1 manifest source is:

```text
assets/HextechRunes.v0.99.1.json
```

It is copied to the package as:

```text
HextechRunes.json
```

## Package contents

A deployable v0.99.1 mod folder must contain:

```text
HextechRunes.dll
HextechRunes.pck
HextechRunes.json
```

Install it into the game's `mods` directory as an isolated folder, for example:

```text
mods/HextechRunes_v0991_test/
```

Do not enable this local test package at the same time as a Steam Workshop copy of HextechRunes.

## Existing packaging script

The existing script is:

```text
tools/build_and_deploy.sh
```

It is currently written for the original author's macOS/zsh environment. On Windows, use an equivalent local script or manually copy the three package files above after building and packing the PCK with Godot 4.5.x Mono.
